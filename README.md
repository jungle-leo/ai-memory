# 个人档案

跨电脑、跨AI共享的个人记忆系统。

## 目录结构

- `USER.md` - 稳定的个人偏好与背景
- `MEMORY.md` - 长期记忆索引
- `PROJECTS.md` - 当前项目、决定、阻塞和下一步
- `memory/inbox/` - 候选记忆（待整理）
- `memory/topics/` - 已整理的主题记忆

## 日常使用

- "记住这件事：……" - 生成候选记忆
- "同步我的记忆" - 同步到远程仓库
- "开始工作" - 先同步，再开始

## 隐私红线

- 不存密码、Token、验证码、私钥
- 不存身份证件、银行资料、税务信息
- 不存未经脱敏的医疗、法律、雇佣信息
